# Engineering Process & Agent Governance Documentation

This directory notes the development process, architectural state, and pair-programming protocols used to build and verify PHALANX.

## Process Artifacts
- **`AGENTS.md`**: Agent behavior guidelines, security boundaries, non-negotiable invariants, and pair-programming protocol.
- **`docs/brain/`**: Continuous architectural state tracking (`STATE.md`), decision log (`DECISIONS.md`), verified empirical facts (`FACTS.md`), findings backlog (`FINDINGS.md`), task execution logs (`LOG.md`), and task prompt specs (`prompts/`).
- **`.agents/`**: Agent rules and operational design specs.

These files are internal development, security audit, and evaluation artifacts, maintained for complete transparency and verifiable security provenance. Public consumer documentation is located in `README.md` and `docs/`.
